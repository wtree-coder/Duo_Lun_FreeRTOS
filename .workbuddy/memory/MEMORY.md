# 项目长期记忆（My_Duo_Lun）

## 电机 CAN ID 映射（Board_A 底盘，已实测确认）

四个舵轮模块 LU/LD/RD/RU，每个模块含一个 6020（舵向）+ 一个 3508（轮向），
6020 与 3508 均用各自电调的 ID1~4：

| 模块 | 6020 反馈(控制0x1FE/0x1FF) | 3508 反馈(控制0x200) |
|------|---------------------------|----------------------|
| LU   | 0x205 (ID1)               | 0x204 (ID4)          |
| LD   | 0x206 (ID2)               | 0x201 (ID1)          |
| RD   | 0x207 (ID3)               | 0x202 (ID2)          |
| RU   | 0x208 (ID4)               | 0x203 (ID3)          |

- 6020 在 hcan2，3508 在 hcan1。
- 0x200 发送槽位按 ID1~4 = { LD, RD, RU, LU }；6020 槽位按 ID1~4 = { LU, LD, RD, RU }。
- GM6020 控制帧：电压控制 0x1FF，电流控制 0x1FE（需固件>=1.0.11.2 且开电流环）。
