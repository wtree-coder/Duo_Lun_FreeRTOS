## Board_C 云台自稳代码审查（只审查未改码）

审查范围：`Board_C/Task/Task_Gimbal.c`、`Mid/gimbal_config.c/.h`、`Mid/imu.c/.h`、`BSP/pid.c/.h`、`BSP/motor.c/.h`、`BSP/drv_can.c`、A 板 `Mid/callback.c`。

架构结论：
- C 板 = 云台 + IMU（BMI088，SPI1）主控；A 板 = 底盘（3508×4 + 6020×4），无 IMU 任务。
- CAN 目前**单向 C→A**：C 发 0x300（vx/vy/云台相对角/拨杆），A 只配了 0x300 的滤波器。A→C 无帧，所以底盘角速度无法从 A 板获取。
- 云台串级：外环 IMU yaw → 目标角速度 → 内环电机角速度 → 6020 电流（0x1FF，ID1 反馈 0x205）。
- 任务优先级：Gimbal(osPriorityHigh1) > IMU = Communicate(osPriorityHigh) > Data_Get(Normal)。

主要问题（已向用户提出）：
1. `gimbal_config.c:29-30` 两个 PID 的 Kp/Ki/Kd 全 0；且 `integralLimits=0` 使积分被钳死。
2. BMI088 + `MahonyAHRSupdateIMU` 无磁力计 → yaw 纯陀螺积分必漂移（自稳根本问题）。建议 Homing 阶段做 gz 零偏标定。
3. `motor.c:27` Motor_Check 掉线用 `memset` 清整个 Motor_t，会丢 angle_offset/total_round，且 1ms 计数对 1kHz 反馈余量为 0。
4. 外环输出直接当电机目标转速，缺底盘角速度前馈（可用 ω_chassis = d(IMU yaw)/dt − ω_motor 自算）。
5. `Task_IMU.c:33` xLastWakeTime 写在循环内导致非绝对周期，SPI 轮询耗时使实际 dt ≠ PID 里的 1ms。
6. DR16 DOWN 档也是 DISABLE，GIMBAL_SHOOT 死代码；掉线时 out=0 不锁云台。
7. vofa 调试通道重复（0/2 都是 total_encoder），缺 yaw/target_yaw/out。
