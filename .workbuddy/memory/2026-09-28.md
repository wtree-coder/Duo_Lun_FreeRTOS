### FIFO 容量结论（A 板）

- 时钟：SYSCLK=180MHz，APB1=/4 → 45MHz；CAN 位时间 1+10+3=14TQ，Prescaler=3
  → **波特率 = 45M/(3×14) = 1.071 Mbps**，每帧 8 字节约 130 bit ≈ 0.12 ms。
- **CAN1/CAN2 是两个独立外设，各有自己的 FIFO0 硬件**（HAL 用 `hcan->Instance` 索引
  RF0R / sFIFOMailBox），共用的只是"回调函数"，不是队列。深度各 3 格。
- 负载：CAN1 = 4×3508+0x300 = 5 帧/ms ≈ 60%；CAN2 = 4×6020 = 4 帧/ms ≈ 48%。都够。
- 前提：**8 个电机绝不能挂同一条物理 CAN**（9 帧/ms × 0.12 = 1.08 ms > 1 ms，必丢帧）。
- 遗留风险：①回调一次只读一帧且未检查返回值，建议 `while(HAL_CAN_GetRxMessage(...)==HAL_OK)`
  读空；②CAN 中断优先级仍是 5，与 `configMAX_SYSCALL_INTERRUPT_PRIORITY` 同值时
  会被 FreeRTOS 临界区屏蔽，建议降到 4。

## GM6020 硬件要点（官方 RM GM6020 使用说明书）

- **状态灯**：`绿灯每秒闪 N 下 = 电机当前 ID 为 N`（官方原话 "The number of blinks
  indicate the current ID of the motor"）。所以绿灯闪 3 下 = **ID 3，且属正常**。
- 橙灯：闪1=温度>100℃；**闪2=总线上有重复 ID**；闪3=无 PWM 信号；闪4=温度传感器异常。
- 红灯：闪1=电源电压过高；闪4=温度>125℃。
- **ID 映射**：DIP 开关 Bit[2:0] = ID（000 无效，001~111 → ID 1~7）。
  - 反馈帧 ID = **0x204 + 电机ID**（ID1→0x205 … ID7→0x20B）
  - 电压模式控制帧：ID 1~4 → **0x1FF**，ID 5~7 → **0x2FF**，命令范围 −30000~30000
  - 电流模式控制帧：ID 1~4 → **0x1FE**，ID 5~7 → **0x2FE**
    需固件 ≥1.0.11.2 且用 RoboMaster Assistant(≥2.7) 打开"电流环开关"才生效
- **用户确认 0x1FE 是对的** → 本项目使用 GM6020 **电流模式**（且 ID 应在 1~4）。

## 劣弧 / 优弧 结论（用户确认的设计约定）

- `atan2(sinf(d), cosf(d))` / 反复加减 2π 归到 (-π, π] —— 数学上等价，都是 mod 2π，
  但**只会选出劣弧（≤180° 最短路径）**。想走优弧必须保留圈数用连续角。
- 因此：小陀螺 → Move 回正，用现在的归一化 delta 得到的是**劣弧回正**（最快、可能反向）；
  若要"顺着原旋转方向转回去不反向"（优弧），需改用连续累计角（total_encoder 或 IMU 连续 yaw）。
- 归一化成立前提：|真实偏差| < π。云台相对底盘偏角若机械限位 ≥180°，会 alias 成反向。
- 底盘跟随 `wz = KP * delta` 是纯 P，云台匀速转动时有稳态滞后 delta_ss = ω_gimbal / KP
  （KP=2、ω=1rad/s → 滞后约 28°）。要消除需加云台角速度前馈或积分项。
